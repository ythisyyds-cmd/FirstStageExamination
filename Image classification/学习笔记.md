# ResNet18图像分类学习笔记

这项任务我选择了用ResNet18和CIFAR-10来做。选ResNet18是因为它比单纯的CNN复杂一些，但难度还在我可以接受的范围内。我之前有听说过残差连接这种思想，很多比较深的网络也会使用类似的连接方式，所以我也想实际感受一下。

CIFAR-10的数据量和类别数都不算大，每张图片只有32×32，所以训练和验证模型效果都比较方便。ImageNet的图片更大，数据也多得多，对我目前来说训练和检查都困难得多。原来面向ImageNet的ResNet18需要在开头较快缩小图片，不然计算量会很大。但CIFAR-10本来就小，所以使用了3×3、步长为1的卷积来处理，也没有在开头使用最大池化，避免过早丢失图片中的特征。

我一开始对Dataset、DataLoader和batch的关系比较模糊，现在也不太能讲好。大致理解就是Dataset负责提供单张图片和它的标签，DataLoader把这些图片按照batch组织起来。我设置的batch大小是128，所以输入形状是[128, 3, 32, 32]，分别表示128张图片、3个颜色通道和32×32的图片大小。

我原来对batch有一点误解，以为batch变小会让训练轮数变多。其实每一轮训练都会把所有训练图片遍历一遍，batch大小主要影响的是并行计算，batch较小只是让一轮中的batch数量更多，参数更新的次数也更多。batch较大时一次就可以处理更多图片，但也更吃显存。对最后准确率的影响不能简单判断，考虑到数据集大小我觉得64和128比较适合做batch_size，这次使用了128。

训练集使用了随机裁剪和随机水平翻转，这里参考了原始ResNet论文在CIFAR-10实验中的处理思路。我的理解是同一张图片如果以稍微不同的样子进入网络就可以让模型不容易只记住固定的训练图片。测试集不用做这些随机变化，这样每次测试时的条件比较一致。

这个网络里核心思想体现之处和最重要的代码实现是残差块。我对F(x)的直观理解是，它是在原输入x上进行的一次修正。我当时比较困惑的是，为什么要先计算x + F(x)再使用ReLU，而不是先对F(x)用ReLU再相加，x被改变的更少不是更有利于保留原始特征吗。后来找到的解释是，F(x)作为修正量需要允许有正也有负。比如x=3、F(x)=-2时，先相加能得到1，说明它可以把原来的特征减小。如果提前使用ReLU，-2就会变成0，这种负的修正也就没有了。另外，形状不变的残差块接收到的x一般已经经过前面的ReLU，所以当F(x)很小时，相加后再用ReLU仍然可以保留原来的x。

当通道数或图片大小发生变化时，原输入和卷积结果形状不一样，就不能直接相加。我在这里使用了1×1卷积来调整原输入。它既可以调整通道数，也可以配合步长缩小图片，而且它自己也有可以学习的权重，比直接复制通道更灵活。

我一开始在相加时写x += temp，后来发现这是直接在原张量上修改，可能会影响PyTorch保留用于求梯度的数据，所以改成了x = x + temp。后面8个残差块的堆叠、平均池化和最后的线性层，主要是参照经典ResNet18的结构来写。每个残差块中有两个卷积层，8个残差块共有16个，再加上开头的卷积层和最后的线性层，就是ResNet18中的18层。BatchNorm目前只是按照经典结构在用，还不能把它的作用讲得很清楚。

训练时用了交叉熵损失和SGD优化器，并且让程序每轮都输出一次平均loss。最开始只训练10轮，运行的几次没有保存模型参数，测试集准确率大约在72%到79%之间。

我一开始发现第一次训练的每轮loss都比第二次低，所以猜测只看第一轮也许就能判断这次训练会不会更好。后来又多运行了几次，遇到过开始loss高、后面反而超过前一次的情况，也遇到过训练loss更低，但测试集准确率却没有更高的情况。我后来明白，每次的初始参数、数据打乱和随机改变图片都会带来变化，只看开头一两轮不适合提前下结论。训练loss只能反映网络对训练数据学得怎么样，测试集准确率更能反映模型的效果。

后来把训练轮数加到了20轮，最后一轮loss为0.3996，测试集准确率达到了82.99%。这说明增加训练轮数是有效的，但我还不会做进一步的分析，所以现在还不能直接判断准确率主要被什么因素限制，在这个网络结构下的上限大概在哪里。

之后我把训练好的参数保存了下来，这样程序结束后就不需要在下次预测前重新训练。做单张图片预测时，图片经过大小调整并转换成张量后的形状是[3, 32, 32]，还需要增加一个batch这一维，变成[1, 3, 32, 32]才能送入网络。我最后从百度上随便找了一张马的图片，考虑到它的尺寸比CIFAR-10中的图片大得多，模型在测试集上的准确率又不到90%，所以我对它能识别正确没有信心。但是很庆幸最后输出的正好是马，也说明整个流程可以正常运行。

现在这个项目能够训练、测试和预测单张图片，但里面还有很多部分我不熟。我目前还不会系统地选择学习率、batch大小和通道数，BatchNorm也主要是按照经典结构使用。TensorBoard和更复杂的训练方法还没有学习，PyTorch中很多写法也不熟悉。但现在我逐渐能够跟着图片的形状变化去检查网络，也把数据读取、网络训练、测试、保存参数和图片预测这几个环节连了起来。
